# Mapped roads and settlements for road-access screening

Roads, tracks, footpaths and named places from **OpenStreetMap** (ODbL 1.0, (c) OpenStreetMap contributors), one GeoJSON per demo area; regenerate with `python scripts/fetch_roads.py`. Used by `core/disaster/roads.py` to find road links cut by a hazard and the settlements that lose every route out of the scene.
