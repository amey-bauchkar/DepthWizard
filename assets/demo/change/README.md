# Change-screening demo pair (Islahiye, Türkiye)

`islahiye_before_2022-12-27_0.5m.tif` and `islahiye_after_2023-02-07_0.5m.tif`: Maxar WorldView visual imagery before and
after the Mw 7.8 Kahramanmaras earthquake of 6 February 2023, resampled to 0.5 m on one shared grid (EPSG:32637, 1.2 x 1.2 km).
Regenerate with `python scripts/fetch_change_demo.py`.
